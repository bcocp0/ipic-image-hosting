# iPic 图床神器：Mac 配图拖拽即传，8 大图床自动生成 Markdown 链接

写博客的朋友大概都遇到过这种事。

文章写到一半，需要插一张图。于是你打开图床网站，登录，上传，等它转圈，复制链接，再切回编辑器，粘贴。一张图还好，三五张图下来，写作的思路早就飞了。

后来有人琢磨，要是能把这一串动作压成一个动作就好了。iPic 就是干这个的。

## 这玩意儿到底是个啥

iPic 是 macOS 菜单栏里一个小小的图床工具。说它小，是真的小——它就住在屏幕右上角那排图标里，平时不声不响，需要它的时候拖个图过去就行。

它不自己存图片，而是当个"中间人"，把你本地的图片往云存储里一塞，顺手就把外链给你生成好，连 Markdown 格式都替你写好了，直接往编辑器里一粘，齐活。

## 上传方式：懒人福音

iPic 准备了好几条路给你走：

- **拖拽上传**：把图片拖到菜单栏的 iPic 图标上，松手就传，菜单栏还会显示进度
- **快捷键上传**：选中图片按 `Command + U`，走 Finder 服务那条路
- **剪贴板上传**：复制图片后按 `Command + Shift + U`，iPic 一直盯着剪贴板
- **右键菜单**：在图片上右击，选"使用 iPic 上传"

一次性传多张也行，顺序跟选的时候一致。上传完自动给你 Markdown 链接，普通链接和 Markdown 链接之间还能一键切换，切换时会自动转换剪贴板里已有的内容，贴心得很。

## 顺带送的几个小功能

- **上传前压缩**：JPG、PNG、GIF 都能压，有损压缩但肉眼基本看不出差别，省存储又省流量，网页加载也快
- **上传历史**：最近 15 条记录留着，最后 3 张直接在一级菜单里，点一下就复制链接，找回素材很方便
- **全文件格式**：不止图片，啥文件都能往云上扔
- **iPic Mover**：配套有个搬家工具，能一键把已有 Markdown 文件里的图片全部迁移到新图床，图床搬家神器
